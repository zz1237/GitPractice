## Overview
This repository is a hands-on practice and reference project focused on mastering Git and GitHub fundamentals.

## Topics Covered

key areas include:

- **Git workflow**
  - Working Directory
  - Staging Area
  - Local Repository

- **Branching and history management**
  - Merging and resolving merge conflicts
  - Rebasing and merge vs. rebase comparison
  - Time-traveling through Git history
  - Cherry-picking commits
  - Stashing work-in-progress changes
  
- **Managing tracked vs. untracked files**
  - `.gitignore`
  - `.gitkeep`

- **GitHub workflows**
  - Pushing local repositories to GitHub
  - Cloning repositories from GitHub
  - Synchronizing local and remote changes
